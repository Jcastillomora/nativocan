# Nativocan Landing Page

Landing page estática para Nativocan Centro de Desarrollo Canino.

## Tech Stack
- Astro 4.x
- Tailwind CSS 3.x
- Vanilla JavaScript
- Cloudflare Pages

## Development

### Install Dependencies
```bash
npm install
```

### Run Dev Server
```bash
npm run dev
```
Abre http://localhost:4321

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## Updating Content

Todos los contenidos están centralizados en archivos JavaScript para fácil actualización.

Ver documentación completa después de la implementación inicial.
